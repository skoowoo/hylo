Hylo MCP tools are connected (MCP server "hylo"). Skills name them bare, such as `read` or `extract_section`; your client may show them with a server prefix (such as `mcp__hylo__extract_section` or `hylo_extract_section`). If they are not in your tool list yet, search your deferred tools for "hylo" first. Read only what you need: the `extract_*` tools return a note's outline, one section, a line range, its tags, links, lists or code blocks.
