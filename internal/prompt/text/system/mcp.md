Hylo's MCP tools are connected (server "hylo"). Skills name them bare, like `read`; your client may prefix them (`mcp__hylo__read`, `hylo_read`). If they aren't in your tool list, search your deferred tools for "hylo". Read only what you need: the `extract_*` tools return a note's outline, one section, a line range, or its tags, links, lists or code blocks.
