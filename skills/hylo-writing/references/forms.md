# Forms

There are no templates: the user's last piece of the same kind is the template. Take the form from the first of these that exists:

1. **Named by the user**: "in the format of [[last weekly report]]".
2. **Recorded in `/_memory/_voice.md`**: e.g. "Weekly report: this week / next week / risks, saved in /Work/".
3. **The latest note of the same kind**: `search` the title keyword (weekly report / 周报, minutes / 纪要, reading notes / 读书笔记…) and follow the newest one's structure, length and folder.
4. **The default below**, only when none of the above exists.

| Form | Default structure | Length |
| ---- | ----------------- | ------ |
| Weekly report | Done this week / Next week / Risks and help needed | 3–5 items each |
| Meeting minutes | Decisions / Action items (who, when) / Discussion | decisions and actions first |
| Reading notes | One-line verdict / Key ideas / Excerpts / My thoughts | excerpts verbatim |
| WeChat article (公众号) | Title + lede + 3–5 subheadings + ending | 1500–3000 characters |
| X / Twitter thread | First post is the conclusion, one point per post | ≤ 280 characters each, 5–10 posts |
| Xiaohongshu (小红书) | Title ≤ 20 characters, bullet points, conversational | 300–800 characters |
| Email | First sentence: what you need from them / Background / Details | as short as it can be |
| TL;DR | One-sentence conclusion + 3 key points | ≤ 100 words |
