# Beats

## What a beat is

A beat is one move in the article. It does one thing — sets a scene, lands a point, asks a question, drops an aside, twists the angle — then stops where the next beat can pivot.

A beat is sized by what it needs:

- A single sentence if that's all the move is ("And then nothing happened for three weeks.").
- A short paragraph if the move needs setup.
- Several paragraphs if it's a self-contained vignette, argument or example.

A beat that needs five paragraphs and three subheadings is two beats glued together. Split it.

## Writing one beat

Write that beat only. Pull from the sources: paraphrase, split, recombine or quote. Keep dated views dated: "as of 2024-03, X believed Y" is more honest than a timeless claim.

**Drilling into source notes.** Knowledge units link back to the notes they were compiled from. When a unit is thin (no concrete example, quote or detail), read the source note. If you use something the unit doesn't capture, mention it may be worth compiling later.

**Partial reads.** Use the `extract_*` tools when you don't need the whole file.

## Gaps

If a beat the user wants has no support in the sources, say so: "Your notes don't cover this." Then offer: skip it and pivot to what is covered; they give a fragment inline, used for this beat only; or pause, compile a note, and resume. Never fabricate coverage.

## Rhythm

- Append one beat at a time. Never write ahead.
- Re-read the article before every write (`editor_read` in the editor, from disk otherwise). Preserve user edits absolutely; if they rewrote an earlier beat, let it change what comes next.
- "Rewrite that beat" or "try a different beat 3": edit it in place, leave the rest alone. In the editor, `editor_rewrite` on the beat's blocks from a fresh `editor_read`.
- If typing comes back `interrupted`, the user has taken over. Don't retype the rest; re-read and ask how to continue.

## Ending

The article ends when the argument lands, not when the sources run out. Most material won't make it in; that's the point of knowing more than one article can hold. Compiling the finished article back closes the loop: the synthesis it created becomes knowledge.
