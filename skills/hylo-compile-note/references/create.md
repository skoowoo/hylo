# Create — New Knowledge Unit

Synthesize the note's content into a fresh unit. Add no inline citations: everything comes from this one note, and `## Sources` is the record.

- `## Sources` starts with this note.
- Frontmatter: `source_notes` holds this note's path; `created_at` and `last_compiled_at` are now; `compile_count: 1`; `perspective` is the note's `source_perspective`.

Write it with `create` at `/_knowledge/<Title>.md`.
