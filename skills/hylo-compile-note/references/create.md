# Create — New Knowledge Unit

Build the unit around the contribution that passed triage. Include only enough definition and context to make it understandable; do not expand it into a general encyclopedia entry. Keep the strongest examples and leave exhaustive detail in the source. Add no inline citations: everything comes from this one note, and `## Sources` is the record.

- `## Sources` starts with this note.
- Frontmatter: `source_notes` holds this note's path; `created_at` and `last_compiled_at` are now; `compile_count: 1`; `perspective` is the note's `source_perspective`.

Write it with `create` at `/_knowledge/<Title>.md`.
