# Skills 使用指南

Hylo 内置了一套 skill，agent 会根据你的请求内容自动选择合适的 skill 来执行——不需要你显式指定 skill 名字，用中文或英文直接描述需求就行（每个 skill 都同时支持中英文触发）。

本文介绍每个内置 skill 的功能和用法。关于 skill 的安装、管理和自定义方式，见主 README 的 [Skills](../README_ZH.md#skills) 章节。

## hylo-notes —— 保存和修改笔记

负责存和改：新建笔记和速记，修改、移动、重命名、删除笔记。查找东西交给 `hylo-recall`。

**适用场景**：保存一条新笔记、随手记一个想法，或者整理已有的笔记。

**提示词示例**

```
把这段话存成笔记，放到 /reading 目录下："..."
随手记一下：记得跟进一下和 Alex 的合作
把“Q3 计划”这篇笔记改名为“Q3 发布计划”
```

## hylo-editor —— 在编辑器里实时写作

直接在你打开的编辑器里写和改笔记，你能看着文字被一个字一个字打出来：笔记会在你面前打开，一个"Agent"光标按自然的节奏输入。它可以写在笔记末尾、某个标题下或者你的光标处，也可以改写或删除某一段、某几个块，或者你选中的内容。每次写入是一个撤销步骤；你自己一敲键盘，agent 就会停下把控制权交还给你。这个 skill 还教会 agent Hylo 的 markdown 方言——wikilink、wiki 图片、思维导图块、任务和表格——让它打出来的内容能正确渲染。需要 Hylo 应用处于打开状态。没打开时，`hylo-writing` 的写作会直接写文件，并用一句话告诉你；如果你明确要看着写，agent 会请你先打开 Hylo。

**适用场景**：看着文字在笔记里写出来。写什么、怎么写归 `hylo-writing`，这个 skill 负责 agent 怎么把字打进编辑器。

**提示词示例**

```
在编辑器里给这篇笔记写个开头。
从我光标的位置接着写三个例子。
把我选中的这段改得更简洁一些。
把「计划」这一节改成思维导图。
```

## hylo-compile-note —— 把笔记编译成知识

把一条原始笔记（网页剪藏、日记、播客转录等）编译成一个或多个**知识单元**——针对笔记中提到的人物、概念、公司或想法建立的持久化 wiki 页面。已有的知识单元会被更新而不是重复创建；只有真正有沉淀价值的实体才会成为知识单元，一次性的细节仍然留在原始笔记里。

**适用场景**：把一篇网页剪藏或长笔记转化为结构化、可复用的知识，而不是让它埋没在单独的文件里。

**提示词示例**

```
把笔记 /clips/网络效应.md 编译进知识库
帮我从这篇播客转录里提取知识，更新一下知识库
对 /journal/2026-07-01.md 跑一下 compile
```

## hylo-index-knowledge —— 构建知识索引

扫描知识库，找出还没被收录进任何领域索引的知识单元，并把它们归入合适的索引（必要时创建新的领域索引）。可以反复运行，每次只会新增缺失的条目，不会重复处理。

**适用场景**：在编译了一批新笔记之后，保持知识库的领域索引（`AI.md`、`Business.md` 等）保持最新。

**提示词示例**

```
重新生成一下知识索引
帮我刷新一下领域索引，最近编译了不少新笔记
把知识索引里漏掉的都补上
```

## hylo-memory —— 提取个人记忆

从你的 Short Notes 速记和知识库中提取个人记忆，写入 `/_memory/` 下的七个结构化文件：身份、偏好、目标、信念、人际关系、当前状态、文风（从你的短笔记里学到的写法，加上你明确说过的写作规则和常写文体的格式）。首次运行会扫描最近 90 天，之后每次只做增量扫描。长期没有被强化的记忆会逐渐淡出直至删除。

完整设置方式（包括配置每日定时触发的 bot）见主 README 的[个人记忆（Memory）](../README_ZH.md#个人记忆memory)章节。

**适用场景**：让之后每一次对话都自带关于你的持久化背景信息，不用每次都重新自我介绍。

**提示词示例**

```
请更新我的个人记忆，我是 Skoo，目前在做一个 AI 原生的笔记应用。
帮我跑一下记忆提取，这次也扫描一下 /journal/ 目录。
刷新一下我的个人记忆库。
```

## hylo-recall —— 找、灵感、回顾、探

把东西从你的笔记和知识库里找回来。四种模式：

- **找**：找资源、话题、观点，或者涉及某个内容的所有笔记，不限时间，很久以前写过、已经忘了的也能找回来。问“我对 X 怎么看”时先给你自己的看法并标日期，读到的内容单独标出。给它一条笔记或草稿，它会找出支持和矛盾的内容。
- **灵感**：为你在想或要写的东西找素材：你以前的想法、读到的引文和案例、其他领域的关联，以及你留下的未解问题。
- **回顾**：回顾最近一周或一个月的主题和矛盾；或者随机翻翻历史，挑几篇被遗忘、值得再看的笔记。
- **探**：你的知识体系全貌：按领域索引看分成哪几块、各有多大，知识从哪来，最近在长哪块、哪块沉寂了，和你的目标对不对得上；输出一张思维导图和下一步选项。

都只在对话里回答，除非你之后选择保存。“你写的”和“你读到的”始终分开说。

**提示词示例**

```
找一下我写过的所有关于定价的笔记
我对远程办公怎么看？
帮我找点写 onboarding 文章的素材
回顾一下这个月
随便翻翻，找点我忘了的
我的知识库都有什么？
```

## hylo-setup —— 在聊天里引导设置

完成 onboarding 后的第一次聊天会自动运行它。Hylo 会一步步带你完成设置：先在编辑器里实时写一篇入门指南，再确认你希望用哪种语言交流并记住，vault 还空着的话会简单了解一下你，然后帮你建一个 Recall bot，把写过的东西带回给你（周回顾、随机翻历史、新速记与已有笔记比对，任选），再建一个 News bot，每天早上从你选的新闻源整理一份摘要，再把几篇笔记编译成知识，最后总结一下设置好了什么。进度保存在 `/_setup/progress.md`，随时可以中断，之后再接着来。

**适用场景**：补完之前跳过的设置，或者重做某一步。请求时要明确说是「Hylo 设置」，这样日常聊天里说「设置一下某某」不会误触发它。

**提示词示例**

```
继续 Hylo 设置
重新运行 Hylo 设置
```

## hylo-writing —— 成文、改稿、长文

写作的统一入口，主 bot 默认常开。它先判断有没有现成的文字要动，再按三种模式之一来做：

- **成文**：把你已有的素材（几篇笔记、这周的短笔记、刚才的对话，或把一篇笔记改成另一种格式）写成一篇新笔记。不问问题：自己定标题和文件夹，写进笔记（Hylo 开着时一律在编辑器里实时写，否则直接写文件），末尾列出用到的素材笔记，聊天里只回一两句并给出下一步。原文不动。
- **改稿**：针对现成的文字：引用的选区、当前选区或某篇 `[[笔记]]`。先分清你要的是*意见*（聊天里 3–5 条带引用的意见，原文不动）、*候选*（2–3 个编号版本，选了才写入），还是*替换*（润色、缩短、扩写、翻译、接着写，直接写入，一步可撤销）。只改你指定的范围。
- **长文**：从知识库写一篇有观点的长文。从请求和记忆里猜读者和立场，给出素材表（知识单元优先，不够时加笔记和短笔记）供你确认，然后一段一段写，也可以选择剩下的一口气写完。没有题目时，按最近编译的内容给你三个选题。写完可以编译回知识库。

所有模式都按 `/_memory/_voice.md` 里的文风写。规则说一次（“以后别用破折号”）就记在那里，之后每篇都照做。周报这类固定格式照你上一篇同类笔记写，没有时用简短的内置默认格式。

**适用场景**：所有写作：把笔记汇成一篇、把讨论整理成文、周报和纪要、把笔记改编成其他平台的版本、润色一段或请它提意见，以及基于你的积累写长文。

**提示词示例**

```
把这周的短笔记整理成一篇
把刚才聊的写成笔记
写个周报
把 [[注意力管理]] 改成小红书版
润色一下 / 这段哪里不好？ / 起个标题
写一篇关于「SEO 正在失效」的文章，读者是独立开发者
以后写东西别用破折号
```
