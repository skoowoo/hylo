# Vault 初始化与重建

`hylo init [目录]` 从 Markdown 文件构建笔记所需的派生数据。省略目录时使用当前目录，不读取配置中的 `vault.path`。

```sh
hylo init /path/to/vault
hylo init /path/to/vault --image --force
hylo init /path/to/vault --graph --index --force
```

| 选项 | 完整功能 |
| --- | --- |
| `--image` | 扫描并登记图片，重建正文图片关联及笔记封面。封面选取规则与运行期一致，复用已下载的远程图片，缺少缓存时尝试下载。 |
| `--graph` | 重建知识笔记之间的链接和实体类型索引。 |
| `--index` | 从已登记笔记完整重建全文搜索索引，清除旧搜索文档。 |
| `--preview` | 重新计算笔记摘要、任务统计以及图片和代码标记。 |
| `--force` | 强制重新构建所选功能；没有选择功能时，重新构建全部功能。 |

选项可以组合。不指定功能时执行全部功能；新库先登记笔记，再执行所选功能。已有库的收藏、创建时间等笔记元数据不会因功能重建而被清空，Markdown 和图片源文件也不会被删除。

每项功能成功后，将完成版本记录在 `.hylo/init.json`。普通执行跳过已完成的功能；失败的功能保持未完成状态，下次执行时可重试。状态文件缺失或损坏时会重建状态，空的元数据库也会重新登记笔记。首次使用新命令打开旧库时，会补建尚未记录的功能。桌面端自动初始化使用同一套功能和完成状态，在启动时补齐未完成项。

日常变更仍由运行期插件维护。若怀疑图片、封面或索引有缺失，用对应功能加 `--force`，例如：

```sh
# 同时修复图片登记、正文关联和封面
hylo init /path/to/vault --image --force

# 更换分词或索引配置后重建搜索
hylo init /path/to/vault --index --force
```
