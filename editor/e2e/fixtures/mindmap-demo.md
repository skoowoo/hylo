# Mindmap 演示

一块 `mindmap` 代码块，里面写 markdown 大纲，编辑器把它渲染成一张可平移、可缩放、可折叠的图，能开画中画和全屏。块里存的是纯文本大纲，不是绘图指令。

## 一张能用的图

把一篇文章的骨架摊开，比读一遍全文更容易看出哪里是空的。

```mindmap
# 开发完蛋了，运维的最好时代
## 写代码在贬值
- 需求明确，AI 又快又对
- 代码变成耗材
- 成本挪到「养下去」
## 基础设施在涨价
- 一人一个常驻租户
- 隔离、网络、计费
- 漏洞与 agent 攻击
## 脏活没了，判断还在
- 巡检回滚交给 agent
- 要不要重启
- 责任不能自动化
```

## 规则只有一条

`#` 定根，`##` 定层级，井号越多节点越靠外；列表项按两个空格缩进，挂到最近的标题或列表项下面；段落行不算节点，写了也白写。

## 对的一版

```mindmap
# 主题
## 分支
- 要点
- 要点
## 另一个分支
- 要点
```

## 错的一版

两个 `#` 并列，谁也管不了谁，最后一起挂到一个空节点上，图就散成两棵。

```mindmap
# 根一
- 要点
# 根二
- 要点
```

## 剩下的三句

- 标签几个词就够，超过四五十个字挤成一团
- 两到四层最好看，再深就该拆成两张图
- 节点里能用行内格式和普通链接，wikilink 不解析，会原样显示成双中括号

## 速查表

| 写法 | 效果 |
| --- | --- |
| `#` | 根节点，一张图只留一个 |
| `##` `###` | 层级，井号越多越靠外 |
| `-` 缩进两格 | 挂到最近的标题或列表项下 |
| `1.` 有序列表 | 照样子建树，序号不显示 |
| `- [ ] 任务` | 复选框被丢掉，只留文字 |
| 段落 | 不算节点，直接忽略 |
| `**粗体**` `code` `~~删除~~` | 节点内可用 |
| `[文字](https://…)` | 普通链接可用 |
| `[[笔记]]` | 不解析，显示成双中括号 |
